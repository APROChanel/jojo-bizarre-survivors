# JoJo's Bizarre Survivors (แฟนเกม)

เกม 2D Pixel Art แนว Survivor / Bullet Heaven จักรวาล JoJo + **Streamer Mode** (เชื่อม TikTok LIVE — ของขวัญ/ใจ/ติดตาม เสกมอน เสกบอส ช่วยหรือป่วนสตรีมเมอร์)

## ⬇ ดาวน์โหลด
**[โหลด JoJo_Bizarre_Survivors.exe (เวอร์ชันล่าสุด)](https://github.com/APROChanel/jojo-bizarre-survivors/releases/latest)** — Windows 10/11

1. โหลดไฟล์ `JoJo_Bizarre_Survivors.exe` จากลิงก์ด้านบน
2. ดับเบิลคลิก → เกมเปิดเป็นหน้าต่างเกม (ครั้งแรก Windows อาจเตือน "Windows protected your PC" → กด **More info → Run anyway**)
3. เวอร์ชันใหม่อัปเดตเองอัตโนมัติ ไม่ต้องโหลดใหม่

- ปิดหน้าต่างเกม = ปิดโปรแกรมทั้งหมด • F11 = เต็มจอ
- Streamer Mode: เมนูหลัก → Streamer Mode → แท็บ "ไลฟ์" ใส่ชื่อช่อง TikTok แล้วกด "เชื่อม"
